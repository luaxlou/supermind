# Supermind

Supermind 是基于 Codex 的产品开发协作插件。

## 为什么需要 Supermind

代码生成越来越容易，但用户仍需反复解释产品背景、协调工具和辨别已有成果是否可用。任务之间缺少衔接，经验散落在对话和项目里，重复劳动并未随之消失。

Supermind 要减少这部分组织成本，让用户聚焦目标和关键判断。衡量它的标准是实际收益与交付效果，而不是生成了多少代码、执行了多少流程或收集了多少能力。

## 核心能力

**延续产品上下文**：理解已有需求、代码和约束，将新的意图转化为可验证的交付，在现有成果上持续演进。

**按需组织技能与工具**：根据当前问题选择规划、实现、调试、验证等方法，不机械套用工作流。Superpowers 和其他插件都是可选能力来源。

**沉淀值得复用的能力**：主动发现、评估并协助抽象通用成果，建立可检索的能力库。只有收益值得承担提取和维护成本时才沉淀；业务实现不能靠改名冒充通用能力，每次具体复用都须人工确认。

## 如何安装

在支持插件的 Codex 环境中，打开终端执行：

```bash
codex plugin marketplace add luaxlou/supermind --ref main
codex plugin add supermind@supermind
```

安装后新建一个 Codex 任务即可使用。

## 如何使用

在任务中输入 `$supermind`，然后直接描述目标，例如：

> 用 Supermind 给这个产品增加手机号登录功能。

> 用 Supermind 查看能力库，评估是否已有适合当前项目的登录能力。

首次使用能力库时，需要指定或创建一个 GitHub 私有仓库，并完成 GitHub 命令行认证；后续由本地工具管理和增量同步。
