# Supermind

让每一次开发，都为产品创造价值，为下一次开发积累能力。

Supermind 是面向 Codex 的产品开发协作工具。它围绕产品目标理解需求、组织工作、验证结果，并在开发过程中发现值得沉淀的通用能力。

## 为什么需要 Supermind

生成代码越来越容易，但产品开发的难点并没有消失：什么值得做，如何延续已有设计，哪些工作不必重复，以及如何确认结果真的有效。

如果每个任务都从头开始，经验就停留在对话里，能力散落在项目中，人仍要反复解释背景、挑选工具和协调步骤。

Supermind 希望把这些工作连接起来：让用户聚焦目标与关键判断，让 AI 围绕目标持续推进，并把有价值的成果带到下一次开发中。

## 我们坚持什么

- **价值优先**：以实际收益和交付效果衡量工作，而不是代码量、流程数量或能力库规模。不值得做的事，不为完整性而做。
- **持续演进**：理解已有产品和约束，在现有成果上前进，不把每次需求都当成重新开始。
- **有价值才复用**：主动发现、评估并协助抽象通用能力。具体业务实现只是来源材料，不能靠改名变成通用模块；提取和维护的成本也必须算进去。
- **自动推进，保留人的判断**：减少重复操作，用证据支持决策。每次具体复用都由人确认，发现能力不等于获准使用。

## 核心能力

**理解目标，推进交付**：把产品意图转化为可观察的结果，围绕当前需要开展新增、调整、修复、验证和发布，保持前后工作的连续性。

**按需组织技能与工具**：根据问题选择合适的能力，让用户不必成为工作流调度员。Superpowers 和其他插件都是可选能力来源，不限定 Supermind 的定位。

**让开发成果能够积累**：通过可检索、可理解的能力库，记录来源、边界、状态和证据；在重复建设前评估已有成果，并用真实使用结果改进后续判断。

Supermind 的目标不是积累尽可能多的能力，而是让每一次沉淀，都能减少未来的重复劳动。

## 如何安装

在支持插件的 Codex 环境中，打开终端执行：

```bash
codex plugin marketplace add luaxlou/supermind --ref main
codex plugin add supermind@supermind
```

安装后新建一个 Codex 任务即可使用，无需安装 Superpowers。

## 如何使用

在任务中输入 `$supermind`，然后直接描述目标，例如：

> 用 Supermind 给这个产品增加手机号登录功能。

> 用 Supermind 查看能力库，评估是否已有适合当前项目的登录能力。

不必手动安排工作流。Supermind 会理解现状、组织工作，并在关键选择及每次具体复用前请你确认。

首次使用能力库时，需要指定或创建一个 GitHub 私有仓库，并完成 GitHub 命令行认证；后续由本地工具管理和增量同步。
